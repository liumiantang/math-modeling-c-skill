
# 数学建模项目固定交付格式规范

## 源文件

- 文字说明、问题分析、模型说明和论文源稿统一使用 Markdown（.md）。
- 不使用 Word 作为协作源文件；最终参赛稿由 Markdown 编译为 PDF。
- 公式直接写 LaTeX 语法，例如 $x_i$、$\sum_i x_i$ 和独立公式 $$\min_x f(x)$$。
- 禁止 Word 公式对象、公式截图和从 Word 复制出的不可追溯公式。

## 图形

MATLAB 优先使用：

    fig = gcf;
    set(fig, 'Renderer', 'painters');
    exportgraphics(fig, 'figures/q1_result.pdf', 'ContentType', 'vector');

- 图形文件名只允许 ASCII 英文、数字、下划线或连字符，不使用中文和空格。
- 出图前坐标轴、图例和标题字号原则上不低于 12 pt。
- 禁止截图 MATLAB 窗口。
- 热力图等确需位图时，使用至少 300 DPI 的 PNG。
- 图中文字、图例和数值标签必须来自 MATLAB 结果或结果清单。

## 表格和数字

- 表格、指标、参数扫描和结果数字使用机器可读 CSV。
- 不交手工排版表，不把数字从 MATLAB 截图或 Word 表格中抄回论文。
- 论文中的表格由 Markdown/LaTeX 模板根据 CSV 统一生成三线表。
- 所有论文数字都应能追溯到 result_manifest.csv、结果 CSV 和生成脚本。

## 代码

- 交付实际运行的原始 MATLAB .m 文件。
- 附录直接引用同一份源文件，例如 \lstinputlisting{src/q2_model.m}。
- 不复制一份“论文代码”代替实际运行代码。
- 主入口、配置、共享函数、验证脚本和敏感性分析脚本都要登记。
- 代码改动后必须重新运行并更新结果清单。

## 推荐目录

    manuscript/*.md
    figures/*.pdf
    figures/*.png
    tables/*.csv
    results/*.csv
    src/*.m
    logs/*
    result_manifest.csv

## 交付检查

- [ ] Markdown 可以独立编译为最终 PDF。
- [ ] 公式为可编辑 LaTeX。
- [ ] 矢量图可以直接插入 LaTeX。
- [ ] 图形文件名无中文、无空格。
- [ ] 所有结果表为 CSV。
- [ ] 附录代码就是实际运行的 .m 文件。
- [ ] 代码、CSV、图形和论文数字一致。
